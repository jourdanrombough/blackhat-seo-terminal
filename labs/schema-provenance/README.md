# Content Warehouse schema provenance

Five unmodified generated Elixir model files from the public Hex package `google_api_content_warehouse 0.4.0`. Copyright headers and the package Apache 2.0 license are retained. These are reference documents; nothing is executed.

The package and release response were retrieved on 2026-09-17. The registry records insertion on 2024-03-28. The full downloaded package remains in the source project's `qa/evidence/leak-content-warehouse-0.4.0/`; the public download URL and SHA-256 are in `manifest.json`. Registry checksum agreement verifies bytes against one registry, not independent authenticity or current deployment. Google's separate May 2024 acknowledgment concerns the leaked documentation generally.

`manifest.json` maps the seven selected names/strings to exact modules, file hashes and first context lines. Read the entire supplied file before interpreting a field. In particular `chrome_trans_clicks` is text inside the `topUrl` description, not a declared field in that module. No total module/attribute count is claimed. Hash with `shasum -a 256 FILE`; line numbers start at 1.
