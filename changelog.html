Editorial revision and build dates are separate. This tracker covers every page; it does not claim that every source, price or outcome was independently verified.

v9.4 · September 28, 2026 · Link Juice Simulator & Spintax Machine

  • Added the Spintax Machine: a sentence is expanded into spintax from a small built-in thesaurus, 50 versions are spun on an animated slot machine, and four duplicate checks (exact match, word 3-gram overlap, sentence skeleton, synonym-normalised) run on the output with a 50×50 similarity heatmap. Runs entirely in the browser and sends nothing anywhere; the checks are illustrative, not a description of Google's systems.
  • Added an interactive PageRank sandbox: pages as nodes, links as pipes, and link equity shown as particles that flow along follow links, evaporate on nofollow links and stop on devalued links.
  • Seven scenarios (natural web, PBN, link wheel, nofollow sculpting, link farm, parasite page, sandbox) with briefings linked to the matching chapters, plus tools to add, link, nofollow and delete nodes.
  • A footprint sweep flags nodes whose simulated footprints cross a threshold and devalues their outbound links; a model toggle compares pre-2009 and current nofollow handling.
  • Labeled as a teaching model using classic PageRank (d=0.85). It makes no network requests and does not predict real rankings. Available in the multi-page and portable editions.

v9.3 · September 27, 2026 · Black Hat Oracle

  • Added a domain form, animated terminal analysis, and three linked strategy recommendations selected from eight archive topics.
  • The boot sequence starts after pressing Analyze. Linux-style reports include ASCII illustrations for each strategy.
  • The Oracle is a labeled simulated environment. It makes no domain requests, uses no paid APIs, and does not measure rankings, backlinks, traffic, or penalties.
  • Includes a cancel control, reduced-motion support, repeat runs, a scan transcript, and a downloadable text report. Available in the multi-page and portable editions.

v9.2 · 2026-09-19 · Restricted-verticals integration

  • Added a Restricted Verticals hub plus three chapters (illegal/gray pharma, adult/XXX, alcohol/DTC) built to the standard technique template, documenting how channel-excluded industries pursue organic traffic and how each is detected and defended against.
  • Pharma chapter is Tier C: mechanism, incident analysis and defensive detection only, no exploit; it leans on the leaked-ledger economics (Click Trajectories, PharmaLeaks) and the payment-chokepoint finding.
  • Added six structured case records (GlavMed/SpamIt, RX-Promotion, hacklink market, 2025 SEO-poisoning campaign, adult data-PR, MA DTC compliance sweep), taking the case database to 24 records.
  • Added glossary terms (partnerka, pharma hack, hacklink, age-gate cloaking, traffic trading, payment chokepoint) and timeline rows (2010 SpamIt closure, 2011 value-chain study, 2025 poisoning campaign).
  • Cross-linked the new chapters from overview, start-here, seo-poisoning, parasite-seo, ai-geo, local-seo and detection. No live deployment.

v9.1 · 2026-09-19 · Audit corrections integrated

  • Corrected current policy and legal wording, source mismatches, tool identities and unsupported performance statistics.
  • Separated unexecuted external studies from reproducible synthetic local demonstrations; included fixtures and actual local outputs.
  • Rebuilt search snippets from final section positions, rewrote bundle links and namespaced IDs, and removed unresolved template variables.
  • Repaired tool-filter focus, shifted keyboard shortcuts, dialog labels/focus handling, sort controls and dim-text contrast.
  • Replaced build-generated verification dates with explicit editorial and research dates. Counts distinguish records, reference entries, local demonstrations and proposed studies.

Completion pass · September 17, 2026

  • Added a completed 45-query archive-search evaluation with frozen inputs, protocol, hashes, reproducible code and captured results. This evaluates the local archive, not Google or an AI service.
  • Preserved five raw schema model files and traced seven selected names/strings to the pinned package version, line and hash. A documentation field does not establish production use.
  • Expanded technique walkthroughs and evidence limits; added five named cases for 24 structured records and a dated four-page public offer snapshot.
  • Published 48 product review records and a source-access manifest. Unsupported fields remain explicitly unverified.
  • Repaired desktop and mobile overflow, link identification, text layering and remaining contrast issues. All 32 HTML pages were checked at four viewport widths; automated accessibility checks cover both themes. These checks do not certify assistive-technology compatibility.
  • Corrected the canonical route from the publisher’s public archive link and supplied a local social image. No deployment was performed.
