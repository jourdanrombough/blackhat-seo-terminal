# Black Hat SEO Terminal

A research archive on search and AI manipulation, presented as an interactive terminal. It documents how black hat SEO and AI-search manipulation tactics work, what the evidence does and doesn't support, how search engines detect them, and how to defend against them.

**Live demo:** https://jourdanrombough.github.io/blackhat-seo-terminal/
**Published on:** https://optimizationtheory.com/blackhat-terminal/

> This project is defensive and educational. It separates documented tactics from theory and leaks, cites sources, and focuses on detection and defense. It is not a how-to for manipulating search results.

## What's inside

- **37 pages** covering PBNs, parasite SEO, expired domain abuse, scaled content abuse, SEO poisoning, CTR and NavBoost, prompt injection and AI/GEO manipulation, the Google API leak, restricted verticals, and detection and defense
- **Interactive tools:** a link juice simulator, a spintax machine and a research "oracle"
- **Case database, timeline, glossary and bibliography** with an evidence framework for every claim
- **Offline labs** (`/labs`): small Python and JSON studies you can run locally, including an offline defense lab, an archive search study and a schema provenance study
